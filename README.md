# Aarvik Sharma — 1st Birthday Invitation

A simple, mobile-friendly GitHub Pages website using the birthday invitation image with a clickable **VIEW LOCATION ON MAP** area.

## Files

- `index.html` — invitation page and Google Maps link
- `style.css` — responsive styling
- `assets/invitation.png` — invitation artwork

## Publish with GitHub Pages

1. Create a new **public** GitHub repository, for example `aarvik-birthday`.
2. Upload **all files and folders from this directory**.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will publish the site at:
   `https://YOUR-USERNAME.github.io/aarvik-birthday/`

GitHub says publishing can take up to about 10 minutes after changes are pushed.

## WhatsApp

Share the GitHub Pages URL in WhatsApp. Guests can open the invitation and tap the invisible clickable area positioned over **VIEW LOCATION ON MAP**.

There is also a visible fallback **Open Location in Google Maps** button below the image.

## Important

If you replace the invitation image with a different-size/design image, the `.map-hotspot` percentages in `style.css` may need to be adjusted.
